# Auditvorbereitung

Werkzeug von QM-Dienstleistungen Grosser: Beratungskunden üben vor dem ISO-Zertifizierungsaudit – Dokumente finden (Stufe 1), Fragen beantworten und echte Beispielvorgänge zeigen (Stufe 2).

- Kundenseite: `web/kunde/` (Demo: `web/kunde/?demo`)
- Auswertung für den Berater: `web/auswertung/`
- Datenbank und Edge Functions: `supabase/`
- Testfassung pro Kunde ohne Server: `npm run paket -- daten/<kunde>`

Start: `docs/START.md`. Keine Kundendaten in diesem Repository.
